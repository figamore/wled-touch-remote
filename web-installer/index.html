Set up the bidirectional preview

Preview dependency: until the bidirectional ESP-NOW API is merged upstream, this remote requires figamore's WLED fork. The advanced remote will not work correctly with a standard WLED build.
1

Update WLED first

The installer action builds an OTA/application binary directly from the matching fork revision.

This download is for a generic, classic ESP32 WLED controller. Do not install it on ESP8266, ESP32-S2, S3, C3, Ethernet, or another specialized build. For those targets, build the fork for your own PlatformIO environment.
  1. Back up your WLED configuration.
  2. Download the preview binary below.
  3. Open http://<wled-ip>/update, upload the binary, and let WLED reboot.

Link and discover controllers

In each WLED instance, open Config → WiFi & Network, enable ESP-NOW, and add the remote MAC to Linked MACs. The remote discovers linked controllers on the same radio channel; use Settings → Control Target to control one or all of them.

  1. Connect

    Plug the CYD into your computer with a data-capable USB cable.

  2. Install

    Choose a firmware above, click Install, and select the ESP32 serial port.

  3. Pair

    In WLED, go to Config → WiFi & Network, enable ESP-NOW, and add the MAC from the remote's Info tab to Linked MACs.
